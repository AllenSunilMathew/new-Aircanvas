# Aircanvas

Welcome to the Aircanvas Jekyll site.

This project includes the landing page and game content for the Aircanvas experience.

## Features

- Responsive static site presentation
- GitHub Pages compatible Jekyll setup
- Easy content updates in Markdown

## Explore

- [Games](https://AllenSunilMathew.github.io/new-Aircanvas/games.html)
- [Main site](https://AllenSunilMathew.github.io/new-Aircanvas/)

## Local development

```bash
cd docs
bundle install
bundle exec jekyll serve
```
